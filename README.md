# ACP Pre-Fabrication Checklist

A practical planning checklist for teams coordinating aluminium composite panel (ACP) routing, folding and installation before a production run.

It is intended to help a buyer, fabricator, installer and façade designer agree on the information that should be confirmed before panels are cut. It is not a substitute for approved engineering, project drawings or the processing manual for a specific panel system.

## Use the checklist

- Download or copy [`checklist.md`](checklist.md) into the project handover pack.
- Use [`fabrication-flow.svg`](fabrication-flow.svg) in a project discussion or training handout.
- Confirm every item against the approved drawing revision and the selected panel system.
- Make and inspect a trial fold from the actual panel batch before releasing production.

Read the complete guide, including routing/folding checks, fixing coordination, internal ACP specification references and FAQs:

## Scope

The checklist covers:

1. Panel construction and finish confirmation
2. Fabrication drawing coordination
3. Trial-fold approval
4. Cassette and fixing-detail checks
5. Site handover and first-install inspection
