# ACP first-panel review checklist

Use this project-communication checklist after the first aluminium composite panel, cassette or agreed small review area has been installed and before the same decision is repeated across a wider area.

The checklist records what was compared and what still needs a decision. It does not approve the substrate, fixing system, installation method, fire performance or structural adequacy. Those decisions remain with the responsible project team and its controlled documents.

## 1. Identify the installed condition

- [ ] Record the elevation, zone or other project location used for the first-panel review.
- [ ] Connect the installed panel to the pack or panel-group identifier.
- [ ] Connect that identifier to the current panel schedule or project record.
- [ ] Keep earlier delivery, storage or condition notes attached to the same identifier.

## 2. Align the current evidence

- [ ] Record the drawing or schedule revision used for the review.
- [ ] Identify the controlled colour, sample or finish reference used for comparison.
- [ ] Confirm that the product description and finish reference can be traced to the supplier-issued order documents.
- [ ] Record when a current reference is missing instead of relying on memory or appearance alone.

## 3. Separate observations from decisions

- [ ] Write visible observations without assigning an unverified cause.
- [ ] Separate product-identity questions from installation, engineering and site-safety decisions.
- [ ] Assign each open item to the project role responsible for deciding it.
- [ ] Avoid describing this checklist as a certificate, technical approval or final acceptance record.

## 4. Make the next step reconstructable

- [ ] Record the review date and the project roles represented.
- [ ] Give photographs a location and panel-group reference.
- [ ] State whether the next work area is released, paused or subject to a defined open item under the project's own process.
- [ ] Store the record where the next shift can retrieve it.
