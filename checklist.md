# ACP routing, folding and installation checklist

## 1. Confirm the panel

- [ ] Product code and panel construction are recorded.
- [ ] Total thickness, aluminium skin thickness and core type are confirmed.
- [ ] Coating, colour, gloss and finish direction are confirmed.
- [ ] Required fire classification is checked against the project and tested system.
- [ ] Panels for the trial fold come from the intended batch and finish.

## 2. Confirm the drawing set

- [ ] Fabrication drawing revision is current.
- [ ] Module size, joint width and cassette returns are shown.
- [ ] Fold lines are derived from finished geometry.
- [ ] Stiffener, corner reinforcement and suspension details are shown.
- [ ] Drainage, ventilation, perimeter closure and movement provisions are coordinated.

## 3. Approve the trial fold

- [ ] Reverse-side machining method follows the applicable manufacturer manual.
- [ ] Tooling, groove geometry and settings are trialled on the actual panel.
- [ ] Groove is consistent and clear of swarf along the full fold line.
- [ ] Fold is made on a clean, level and supported work surface.
- [ ] Visible face, corner radius and alignment are checked under normal light.
- [ ] Approved tool and setup are recorded before production.

## 4. Coordinate fixing and installation

- [ ] Fixing system and supporting rail/subframe are identified.
- [ ] Panel movement provisions follow the approved system detail.
- [ ] Fasteners, brackets and accessories are compatible with the selected system.
- [ ] Contact between dissimilar materials is addressed where the approved detail requires it.
- [ ] Handling and storage plan protects the visible face and panel edges.

## 5. Inspect the first installation

- [ ] Panel identity, batch and protective-film status are recorded.
- [ ] Alignment, joint consistency and corner quality are reviewed.
- [ ] Visible face is checked for scratches, distortion and unwanted direction changes.
- [ ] Site observations are fed back before the remaining panels are installed.
